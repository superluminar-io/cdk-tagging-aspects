# CDK Tagging Aspects — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish a JSII CDK library with a general-purpose `FilteringTagAspect` (pluggable `IResourceFilter`) and a ready-made `AwsAiWorkloadTagAspect` for AWS partner AI workload compliance tagging.

**Architecture:** JSII TypeScript project bootstrapped via projen `AwsCdkConstructLibrary`. Three public exports: `IResourceFilter` interface, `FilteringTagAspect` (core aspect that visits every node and applies tags to `CfnResource` nodes passing the filter), `AwsAiWorkloadTagAspect` (concrete aspect with built-in filter for SageMaker, Bedrock, and Comprehend resource type prefixes). CDK's aspect engine handles tree traversal.

**Tech Stack:** Node.js ≥18, TypeScript 5, JSII ~5.7, projen (`AwsCdkConstructLibrary`), aws-cdk-lib v2, Jest, jsii-pacmak / publib (Python/Java/Go/.NET publishing)

```typescript
import { IAspect, CfnResource } from 'aws-cdk-lib';
import { IConstruct } from 'constructs';

export interface IResourceFilter {
  matches(node: IConstruct): boolean;
}

export class FilteringTagAspect implements IAspect {
  private readonly tags: { [key: string]: string };
  private readonly filter: IResourceFilter;

  constructor(tags: { [key: string]: string }, filter: IResourceFilter) {
    this.tags = tags;
    this.filter = filter;
  }

  public visit(node: IConstruct): void {
    if (!this.filter.matches(node)) return;
    if (!CfnResource.isCfnResource(node)) return;
    const cfn = node as CfnResource;
    for (const [key, value] of Object.entries(this.tags)) {
      cfn.tags.setTag(key, value);
    }
  }
}
```

```typescript
import { CfnResource } from 'aws-cdk-lib';
import { IConstruct } from 'constructs';
import { FilteringTagAspect, IResourceFilter } from './filtering-tag-aspect';

const AI_SERVICE_PREFIXES = [
  'AWS::SageMaker::',
  'AWS::Bedrock::',
  'AWS::Comprehend::',
];

class AwsAiWorkloadFilter implements IResourceFilter {
  matches(node: IConstruct): boolean {
    if (!CfnResource.isCfnResource(node)) return false;
    const cfn = node as CfnResource;
    return AI_SERVICE_PREFIXES.some(prefix => cfn.cfnResourceType.startsWith(prefix));
  }
}

export class AwsAiWorkloadTagAspect extends FilteringTagAspect {
  constructor(tags: { [key: string]: string }) {
    super(tags, new AwsAiWorkloadFilter());
  }
}
```

## Notes

- **Bedrock AgentCore resource types:** At time of writing, Bedrock AgentCore resources use the `AWS::Bedrock::` prefix. Verify this is still true when implementing — if a separate prefix appears (e.g., `AWS::BedrockAgentCore::`), add it to `AI_SERVICE_PREFIXES` in `src/aws-ai-workload-tag-aspect.ts`.
- **Raw CfnResource tags:** Tests use `new CfnResource(stack, id, { type: '...', properties: {} })` to avoid importing specific L1 modules. CDK's `CfnResource.tags` is always initialized as a `TagManager` and `setTag` works for any resource type.
- **Adding more named aspects:** To add a new named aspect (e.g., `AwsGenAiTagAspect`), follow the same pattern as `AwsAiWorkloadTagAspect` — create a file in `src/`, export from `src/index.ts`, add tests.
